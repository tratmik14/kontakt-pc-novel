# Контакт — твой первый собранный ПК

Интерактивная HTML-новелла о выборе комплектующих в магазине компьютерной техники.

- 8 комплектующих с понятными объяснениями и сравнением ценовых уровней.
- 15 мультяшных сцен и галерея.
- 3 концовки: покупка дешёвого, среднего или дорогого ПК.
- Сохранение прогресса в браузере.
- Все ресурсы встроены в index.html, внешние зависимости отсутствуют.

Для локального запуска откройте index.html в браузере. Цены и конфигурации учебные. Иллюстрации созданы с помощью ImageGen.
